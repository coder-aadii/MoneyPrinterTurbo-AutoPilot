# Facts Sun Le Bhai character asset provenance

The project owner supplied the original and expanded Facts Sun Le Bhai stickman
PNG files for this project and decided to include the canonical character pack
in this repository. The artwork was created with OpenAI ChatGPT image-generation
assistance. Some expression variants were derived from the original generated
pack.

The exact original creation dates have not been independently verified. No
third-party character reference, separate source artwork, or third-party license
is documented in the available project records. The source sheet named in an
older manifest is not included here. This provenance note does not invent a
named artist or photographer, assert copyright registration, grant a separate
license, or claim exclusive copyright protection.

The 34 supplied files consisted of 12 base poses in each of two versions and 10
additional expression variants. The 12 v1 base images and their corresponding
v2 images decode to identical pixels after transparent padding to the canonical
306 × 429 canvas. The v2 encodings are retained; the redundant v1 copies are not
included. The consolidated v3 manifest records canonical pose IDs, aliases,
relative paths, dimensions, alpha bounds, anchor coordinates, and SHA-256 hashes.
